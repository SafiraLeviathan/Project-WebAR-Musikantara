# ZIP 2 - Backend & Deployment

Paket ini menjadi bagian Anggota 2.

Tempatkan isi ZIP ini di root repositori. Paket mencakup:
- Hono API dan server pengembangan Bun.
- Konfigurasi workspace dan TypeScript.
- Konfigurasi Vite serta Cloudflare Workers.
- Pemeriksaan kelengkapan dan ukuran aset.
- Panduan project, atribusi sumber aset, dan workflow deployment GitHub Actions.

Paket ini memerlukan folder `frontend/` dari ZIP 1 dan folder `assets/` dari ZIP aset agar build dan deployment berhasil.
